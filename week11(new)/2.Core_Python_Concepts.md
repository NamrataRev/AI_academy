# Core Python Concepts

## 1. Variables — Naming and Storing Values
A **variable** is a named box in the computer's memory that stores a value. In Python, you use the assignment operator (`=`) to assign a value to a name.

```python
score = 85
customer_name = "Priya"
```
**Rules and Conventions:**
- Use descriptive names (`total_price`, not `x`).
- Use `snake_case` (all lowercase, separated by underscores).
- Variables can be reassigned to hold new values at any point in the program.

## 2. Data Types
Every value in Python has a specific **data type**. The four foundational types are:

| Data Type | Python Name | What It Stores | Example |
|---|---|---|---|
| **String** | `str` | Text (wrapped in quotes) | `"Hello World"` |
| **Integer** | `int` | Whole numbers | `42` |
| **Float** | `float` | Decimal numbers | `19.99` |
| **Boolean** | `bool` | True or False values | `True` |

You can check a variable's type dynamically using the `type()` function:
```python
print(type(42))      # <class 'int'>
print(type("42"))    # <class 'str'>
```

## 3. If / Else — Writing Decision Logic
Decision logic allows your program to take different actions based on conditions using `if`, `elif`, and `else`.

```python
amount = 600

if amount >= 1000:
    print("Premium discount applied!")
elif amount >= 500:
    print("Standard discount applied!")
else:
    print("No discount available.")
```
**Key points:**
- The condition must end with a colon (`:`).
- The code block inside the condition **must be indented**.
- Use `==` to check for equality, not `=`.

## 4. For Loops — Repeating an Action Across a List
A **for loop** is used to repeat a block of code across a collection of items, such as a list.

```python
prices = [10.50, 20.00, 5.99]
total = 0

for price in prices:
    total += price
    print("Added item:", price)

print("Total cost:", total)
```
**Key points:**
- The loop assigns each item in the list to the temporary variable (`price`) one by one.
- The block of code inside the loop executes once for every item in the list.
- Just like `if` statements, the body of the loop must be indented.
