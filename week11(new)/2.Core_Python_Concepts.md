## 1. Variables — Naming and Storing Values

A **variable** is a name that refers to a value stored in the computer's memory. Think of it like a labelled box: the label is the name you choose, and the box holds whatever value you put inside. You create a variable using the **assignment operator**, the single equals sign `=`, with the name on the left and the value on the right.

### Creating and Reassigning Variables
```python
item_price = 149
print(item_price)

item_price = 249  # reassignment — the old value (149) is replaced
print(item_price)
```
In Python, `=` performs an **action**: it binds the name on the left to the value on the right. It does not mean mathematical equality. 

### Identifier Rules and Conventions
- May contain letters, digits, and the underscore `_`.
- Must **not start with a digit** — `age2` is legal, `2age` is not.
- Must not be a **reserved keyword** (`if`, `for`, `class`, `True`, `False`, etc.).
- **Best Practice:** Follow the `snake_case` convention: all lowercase words separated by underscores, e.g. `total_price`.

## 2. Data Types

Every value stored in a variable has a **data type** — it tells Python what kind of value it is, and what operations are valid on it. Python uses **dynamic typing**, meaning you never declare a type in advance. Python infers it from the value.

| Data Type | Python Name | What It Stores | Example |
|---|---|---|---|
| **String** | `str` | Text data, written inside quotation marks | `"Hello"` |
| **Integer** | `int` | A whole number with no decimal point | `42` |
| **Float** | `float` | A number written with a decimal point | `42.0` |
| **Boolean** | `bool` | A truth value: exactly `True` or `False` | `True` |

### Using `type()`
You can check any variable's data type using the built-in `type()` function:
```python
customer_name = "Ananya Roy"
delivery_fee = 29.50
seats_booked = 2
is_paid = False

print(type(customer_name))  # <class 'str'>
print(type(delivery_fee))   # <class 'float'>
print(type(seats_booked))   # <class 'int'>
print(type(is_paid))        # <class 'bool'>
```

## 3. If / Else — Writing Decision Logic

A **conditional** is a control structure that runs one block of code or another depending on whether a boolean expression evaluates to `True` or `False`. In Python, the primary tools are `if`, `elif`, and `else`.

### Basic `if` / `else`
```python
restaurant_open = True

if restaurant_open:
    print("Welcome to TastyBite!")
else:
    print("Restaurant is currently closed.")
```
**Important:** Python uses **indentation** to define blocks of code. The indented lines after the `if` run only when the condition is `True`.

### Multi-branch Decisions with `elif`
```python
cart_value = 350.0

if cart_value >= 500:
    delivery_fee = 0.0
elif cart_value >= 200:
    delivery_fee = 20.0
else:
    delivery_fee = 40.0

print("Delivery fee: Rs.", delivery_fee)
```
Conditions are checked **top to bottom**. Python runs the block for the **first** condition that is `True` and skips the rest.

### Compound Conditions
Real decisions often involve checking more than one thing at a time.
- `and` — both conditions must be `True`
- `or` — at least one condition must be `True`

```python
cart_value = 350.0
is_premium_member = True

if cart_value >= 500 or is_premium_member:
    delivery_fee = 0.0
else:
    delivery_fee = 40.0
```

## 4. For Loops — Repeating an Action Across a List

A **loop** repeats a block of code multiple times. A **`for` loop** repeats a block once for each item in a sequence.

### Looping Over a Fixed Sequence
```python
coach_names = ("S1", "S2", "S3")

for name in coach_names:
    print("Checking Coach", name)
```
Python pulls one item at a time from `coach_names` and runs the indented body once with that item.

### Looping a Specific Number of Times with `range()`
Sometimes you want to repeat something a fixed number of times. Python's built-in `range()` function generates a sequence of numbers:

```python
for coach in range(1, 4):
    print("Checking Coach", coach)
```
**Note on `range()`:** The stop value is always **exclusive**. `range(1, 4)` produces `1, 2, 3`. It does not include `4`.

### Using `break` and `continue`
- **`break`** ends the loop immediately — no further iterations run.
- **`continue`** skips the rest of the current iteration and jumps to the next one.

```python
attendance = ("Present", "Present", "Absent", "Left")

for status in attendance:
    if status == "Left":
        print("Attendance stopped.")
        break
    if status == "Absent":
        continue
    print("Student is Present")
```
